# Hamro Motors

Premium desktop-first car showroom website built with HTML, CSS and JavaScript.

## Run
1. Open the folder in VS Code.
2. Use the Live Server extension on `index.html`.
3. No Node.js, MongoDB or server setup is required.

## Local data
Customer accounts, favorites, pre-orders, reviews and admin-edited inventory are stored in the browser using localStorage.

## Admin
The private administrator account is initialized locally. The current local credentials are username `admin` and password `hamro123`; change them in `js/main.js` if you want different local credentials.

Important: because this is frontend-only, the admin protection is suitable for local/personal use, not secure public production authentication.
